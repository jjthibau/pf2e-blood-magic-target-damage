# Changelog

## 0.3.0

- First public packaged release; gameplay code matches the previously playtested0.3.0 module.
- Supports Phoenix, Diabolic, Undead, Aesir, Elemental and Psychopomp immediate-damage Blood Magic.
- Adds per-bloodline benefit choices and conservative support for legacy bloodline items.
- Preserves native damage application, IWR, shield Block, Undo and previous Phoenix preferences/cards.
- Adds public install/update URLs, MIT license, contributor documentation and automated release packaging.
- Requires Foundry14.369 within generation14 and exactly PF2e8.6.0. Other PF2e versions disable automation.

## 0.2.1

- Adds the optional bonus-before-multipliers house rule, enabled by default, with native Half/Double and shield handling.

## 0.2.0

- Merges Phoenix bonus damage into native damage before IWR instead of applying a separate damage packet.
