# Security reports

Use [GitHub private vulnerability reporting](https://github.com/jjthibau/pf2e-blood-magic-target-damage/security/advisories/new) for permission bypasses or exposure of private information. Use public issues for ordinary damage or UI bugs. Do not post secrets, campaign exports or private player data.

The current0.3.x line receives fixes. Compatibility is limited to the versions documented in the manifest. This module uses Foundry's normal ownership and GM damage workflows and does not contact external services.
